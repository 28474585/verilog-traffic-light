# 基于 FPGA 的交通红绿灯控制器（Verilog HDL）

> 项目时间：2025.10 – 2025.11

使用 Verilog HDL 完成交通红绿灯控制器的有限状态机设计：南北 / 东西两个方向按四相位循环切换，带两位数字倒计时显示；按下紧急按钮后两个方向同时转红灯，松开后从原状态继续。通过 ModelSim 完成功能仿真，在 Efinity 中综合、布局布线并下载到 Efinix 开发板验证。

## 功能

- **四相位循环**，每个相位带倒计时：

  | 相位 | 北向 | 西向 | 时长 |
  |---|---|---|---|
  | S1 | 红灯 | 绿灯 | 20 s |
  | S2 | 红灯 | 黄灯 | 5 s |
  | S3 | 绿灯 | 红灯 | 20 s |
  | S4 | 黄灯 | 红灯 | 5 s |

  红灯时长（25 s）等于另一方向的绿灯加黄灯，两向倒计时同步递减。

- **倒计时显示**：动态扫描方式驱动 4 位数码管，依次显示「西向个位 → 西向十位 → 北向个位 → 北向十位」，扫描频率远高于人眼分辨，看起来是同时点亮。

- **紧急通行**：`emergency` 为高时两个方向转全红并保持倒计时数值，信号撤销后从当前相位继续计时。状态机以 1 Hz 节拍运行，因此响应发生在下一个节拍。

## 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | in | 1 | 系统时钟 50 MHz |
| `rst_n` | in | 1 | 复位，低有效 |
| `emergency` | in | 1 | 紧急通行按钮 |
| `ledn` | out | 2 | 北向灯：`00` 红 / `01` 绿 / `10` 黄 |
| `ledw` | out | 2 | 西向灯：同上 |
| `north` | out | 5 | 北向倒计时（十进制值） |
| `west` | out | 5 | 西向倒计时（十进制值） |
| `sec_ge` | out | 8 | 数码管段选（共阴编码） |
| `led` | out | 4 | 数码管位选，低有效 |

## 模块结构

`light.v` 内包含四部分逻辑：

| 部分 | 作用 |
|---|---|
| 分频计数 | 50 MHz 时钟经 50 000 000 分频得到 1 Hz 节拍 `clk_1hz`，作为状态机的计时时钟 |
| 状态机 | 4 个相位状态，按倒计时归零切换；紧急信号优先，直接输出双红并冻结计数 |
| 数码管扫描 | 系统时钟驱动 2 位计数器轮流选通 4 个数位，每拍送入对应倒计时的一位数字 |
| 七段译码 | 把 0–9 的数字转换为段选码，组合逻辑实现 |

状态定义与转移：

```
S1 西绿(20s) ──西向计零──► S2 西黄(5s) ──计零──► S3 北绿(20s) ──北向计零──► S4 北黄(5s) ──计零──► S1
        ▲                                                                                         │
        └─────────────────────── emergency 有效时：双向全红，计数保持不变 ◄──────────────────────────┘
```

## 仿真

ModelSim 中建立工程，加入 `rtl/light.v` 与 `sim/light_tst.v`，顶层设为 `light_tst`，运行功能仿真并观察灯态与倒计时波形。

也可以用 Icarus Verilog 快速编译检查：

```bash
iverilog -g2005 -o light_tb.vvp -s light_tst rtl/light.v sim/light_tst.v
vvp light_tb.vvp
```

> 分频计数按真实的 50 MHz 时钟设计，仿真时若要快速看到相位切换，可临时把分频上限调小（如 49），验证完再改回。

## 综合与下板

在 Efinity 中新建工程，添加 `rtl/light.v` 作为顶层，按所用 Efinix 开发板的原理图配置时钟、按键、数码管与 LED 的引脚约束，然后综合、布局布线、生成比特流并下载到开发板验证。

仓库只保存 RTL 与 testbench，不包含具体开发板的工程文件与引脚约束。

## 可以继续改进的地方

- `emergency` 是异步输入，当前直接进入状态机。更稳妥的做法是先经两级触发器同步，避免亚稳态；本项目在实验条件下未出现异常，但这是后续值得补上的一环。
- 倒计时目前由状态机内部维护，若要支持动态调整配时，可以改成参数化或寄存器配置。
