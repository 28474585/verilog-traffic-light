# 设计说明

## 1. 整体结构

整个控制器放在一个 `light.v` 模块里，按功能分为四块：

1. **1 Hz 节拍生成**：对 50 MHz 系统时钟计数，每 50 000 000 个周期产生一拍 `clk_1hz`。
2. **相位状态机**：以 `clk_1hz` 为时钟，维护当前相位和两向倒计时。
3. **数码管动态扫描**：用系统时钟高速轮流选通 4 位数码管。
4. **七段译码**：把十进制数字转成段选码。

分频计数用 `cnt_div < 32'd49999999` 判断，到点清空并把 `clk_1hz` 拉高一拍，因此系统时钟只经过一个组合判断，不需要额外的分频器模块。

## 2. 相位状态机

### 2.1 状态与输出

| 状态 | 编码 | 北向灯 `ledn` | 西向灯 `ledw` | 初值 `north` / `west` |
|---|---|---|---|---|
| S1 | 00 | 红 `00` | 绿 `01` | 25 / 20 |
| S2 | 01 | 红 `00` | 黄 `10` | 5 / 5 |
| S3 | 10 | 绿 `01` | 红 `00` | 20 / 25 |
| S4 | 11 | 黄 `10` | 红 `00` | 5 / 5 |

两向倒计时每拍减 1，红灯方向的计数值始终比绿灯方向多 5，正好覆盖对方的 5 秒黄灯。这样路口两个方向可以显示同一个"剩余时间"概念：绿灯方看到的是自己的剩余绿灯，红灯方看到的是距自己转绿还有多久。

### 2.2 转移条件

- S1：`west == 0` 时进入 S2；
- S2：`north == 0 && west == 0`（5 秒结束）时进入 S3；
- S3：`north == 0` 时进入 S4；
- S4：`north == 0 && west == 0` 时回到 S1。

### 2.3 紧急通行

`emergency` 为高时，状态机保持在当前相位，`ledn` / `ledw` 强制为 `00`（双红），`north` / `west` 保持原值不减。信号撤销后的下一拍，灯态与倒计时从原状态继续。

由于状态机的时钟是 1 Hz，紧急按钮的响应最慢会晚一个节拍（≤ 1 s）。实验室验证时这个延迟可以接受；对响应时间有要求的场合应当用系统时钟直接处理紧急请求。

## 3. 数码管显示

四位数码管共用同一组段选线，靠位选线轮流点亮：

| 扫描序号 | 位选 `led` | 显示内容 |
|---|---|---|
| 0 | `1110` | 西向个位 `west % 10` |
| 1 | `1101` | 西向十位 `west / 10` |
| 2 | `1011` | 北向个位 `north % 10` |
| 3 | `0111` | 北向十位 `north / 10` |

位选是低有效，扫描由系统时钟驱动，每拍换一位，刷新率远高于人眼闪烁频率。由于没有做按位取反的余晖处理，仿真波形上同一时刻只有一个数码管有段选输出，这是扫描显示的正常现象。

## 4. 验证

- **功能仿真（ModelSim）**：观察复位初态、四个相位的灯态与倒计时变化，以及紧急按钮按下 / 松开时是否保持双红并能恢复。
- **编译检查**：仓库中的 testbench 用 Icarus Verilog 12 编译通过，激励包括复位与一次紧急按钮脉冲。
- **板级验证**：Efinity 综合、布局布线后下载到 Efinix 开发板，实际观察相位切换、倒计时与紧急模式。

## 5. 已知限制与改进方向

1. `emergency` 是异步输入，直接进入状态机。工程上应加两级触发器同步后再用，避免亚稳态。
2. 相位时长写死在状态转移里，若要支持不同路口配时，应改成参数或寄存器配置。
3. 紧急状态由 1 Hz 时钟驱动，最慢有一拍延迟；可以用系统时钟做紧急通道，实现即时报文。
